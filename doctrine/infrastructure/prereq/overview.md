# Overview

This folder `prereqs` contains information for *setting up* and *maintaining* prerequisite infrastructure. All this is outside of project scope and is not part of the mainline doctrine - these are details only to be consulted when the are needed by an operator or LLM agent to work with prerequisite infra.

Most of these deal more with `fixed` than `elastic` foundations, as `elastic` resources are project-tier, not prerequisite-tier.

This directory is not exhaustive. Instructions currently exist for:
1. [The Observability Backend](./telemetry_preinfra.md) - HyperDX.

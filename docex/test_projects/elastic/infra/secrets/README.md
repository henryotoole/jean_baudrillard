# Secrets

This folder holds the per-environment `.env` files for this project.
`example.env` is generated by `docex compile` and lists every secret each
env file must define.

`dev.env`, `test.env`, `stage.env`, and `prod.env` are gitignored — they
contain real secrets and must never be committed.

For the smoke-test walkthrough, see `../../../PRE_CUT_CHECKLIST.md`.
